# CodeAlpha Language Translation Tool

A beginner-friendly Flask web app that translates text using the MyMemory Translation API.

## Features
- Text input
- Source and target language selectors
- Translation result
- Copy button
- Basic input validation and error messages

## Requirements
- Python 3.10+
- Internet connection

## Run locally
1. Open this folder in VS Code.
2. Create and activate a virtual environment (optional but recommended).
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the app:
   ```bash
   python app.py
   ```
5. Open the local address shown in the terminal (usually http://127.0.0.1:5000).

## API note
This demo uses the MyMemory translation API. Public services can have rate limits, availability changes, and usage terms. Check the provider's current terms before production use. This app is a learning project, not a guaranteed production translation service.
